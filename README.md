Token Radar (radar-2) ranks pre-token DeFi protocols by an implied token value derived from the sealed DefiLlama snapshot: TVL with diminishing returns, seven-day growth, time run with no token, and chain reach. It covers the full 40-protocol watchlist plus the early radar of pre-token protocols the watchlist leaves out, gives every protocol a concrete seven-step farm plan with costs and times, and renders a dark, sortable, filterable dashboard with a detail view per protocol.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input /path/to/snapshot.json
```
